# Data Analysis

Notebooks using pandas/matplotlib/seaborn/plotly to load, explore, and visualize datasets.

| Notebook | What it does |
|---|---|
| `excel_data_explorer.ipynb` | Reads an Excel file (`Book1.xlsx`) into pandas and previews it |
| `isa_data_explorer.ipynb` | Reads another Excel file and previews it |
| `rainfall_predictions_plot.ipynb` | Loads `rainfall_predictions.csv` and plots it with matplotlib |
| `falcon_dataset_analysis.ipynb` | Explores a CSV dataset (`Falcon.csv`) with pandas/seaborn histograms |
| `sales_data_project.ipynb` | Small end-to-end project: installs packages, loads and analyzes data |
| `histograms_and_charts.ipynb` | Practice building histograms and other chart types |
| `iris_scatter_plotly.ipynb` | Interactive scatter plot of the classic Iris dataset using Plotly Express |
| `numpy_house_comparison.ipynb` | Compares house listings (size, bedrooms, age) using numpy arrays |

Note: several notebooks expect a local CSV/Excel file (e.g. `Book1.xlsx`, `Falcon.csv`) that isn't included here — swap in your own file or re-upload the original to Colab's `/content/` folder.
