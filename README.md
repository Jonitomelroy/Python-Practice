# Python Practice Notebooks

A collection of Python/Jupyter notebooks written while learning data analysis, math/logic fundamentals, and basic Python. Originally scattered across many loosely-named Colab files; organized here by topic.

## Structure

- **[data-analysis/](data-analysis/)** — pandas, matplotlib, seaborn, plotly: loading CSV/Excel files, cleaning data, and charting
- **[math-practice/](math-practice/)** — combinatorics, probability, logic tables, and small algorithm exercises
- **[basics/](basics/)** — core Python fundamentals: strings, functions, loops
- **[apps/](apps/)** — small standalone applications

## Running

Most notebooks are Colab-exported `.ipynb` files. Open them in [Google Colab](https://colab.research.google.com/) or Jupyter. Some reference local files (CSV/Excel) that aren't included — check the first code cell of each notebook for the expected filename.
