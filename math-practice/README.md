# Math & Logic Practice

Small exercises in combinatorics, probability, and logic.

| Notebook | What it does |
|---|---|
| `probability_combinations.ipynb` | Computes probability of exactly N heads using factorial/nCr |
| `combinations_ncr.ipynb` | Standalone nCr (combinations) calculation |
| `logic_truth_tables.ipynb` | Prints AND truth tables for boolean inputs |
| `conditional_practice.ipynb` | Finds the largest of three numbers using if/elif/else |
| `gcd_algorithm.ipynb` | Euclidean algorithm for greatest common divisor |
| `lists_and_sets.ipynb` | Removing duplicates from a list via sets |
| `boxplot_practice.ipynb` | Visualizing a numeric list as a boxplot with seaborn |
